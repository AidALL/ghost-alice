# 팀원별 진행 보고서

팀원(kyu, jy, sk)이 각자 진행한 작업을 같은 형식으로 남기는 폴더입니다. 세 사람의 보고서를 나란히 비교할 수 있도록 [`TEMPLATE.md`](TEMPLATE.md)의 항목과 순서를 그대로 따릅니다.

## 쓰는 방법

1. `TEMPLATE.md` 를 복사해 `project-docs/reports/<작성자>/<YYYY-MM-DD>-<주제>.md` 로 저장합니다. 예: `project-docs/reports/kyu/2026-11-18-windows-verification.md`
2. 여섯 절(목표, 한 일, 결과, 발견한 문제, 확인하지 못한 것, 다음 단계)을 채웁니다. 해당 내용이 없으면 "없음"이라고 적고 절은 지우지 않습니다.
3. 기준 버전이 `test-baseline-2026-11-16` 과 다르면 맨 위에 실제 버전을 적습니다.
4. 각자 브랜치에서 커밋하고 `main` 으로 PR을 올립니다. `main` 에 바로 올리지 않습니다.
5. 발표나 제출용 PDF가 필요하면 이 Markdown 파일에서 만듭니다.
