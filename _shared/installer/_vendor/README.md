Tomli 2.4.0 supplies the TOML 1.1 parser used by `installer.codex_toml` for Codex hook configuration. Its Python source files and MIT license in `tomli/` are unmodified upstream files. This copy keeps Python 3.11+ installations independent of a package manager or network connection.
