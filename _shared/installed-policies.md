# Installed common policies

The response model reads the current host's `_shared` support target from the active detail file under this installation's record root (`~/.ghost-alice` in the standard installation). Use `installed-payload-v3.json` when present. The v2 filename then contains only the schema notice. Otherwise read the `installed-payload-v2.json` detail file. Select the entry whose destination is the `_shared` directory beside the host's installed skills, whose `kind` is `support` and whose `used_by` includes this host. The entry's `source` names the package's `_shared` directory; its parent contains `docs/policies/`. Read the policy file requested by the calling skill there. Read only that target entry instead of loading the entire install record into model input.

These policies govern the current evaluation procedure; they do not require every installed skill to have the package's version. The target record describes an actual support placement, including placement before another installation step failed. That placement neither declares the candidate installation successful nor selects the active management CLI. A missing target, missing policy or unreadable record leaves the policy-dependent evaluation unresolved; do not substitute a development checkout or another host's target.
