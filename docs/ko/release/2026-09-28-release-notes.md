# Ghost-ALICE OS v0.4.0 릴리스 노트

언어: [English](../../release/2026-09-28-release-notes.md) | Korean

## 변경 내용

- 세션 상태·순서 있는 이벤트·발견 메타데이터를 SQLite 트랜잭션으로 저장합니다. 기존 JSON/JSONL은 검증된 가져오기 또는 명시적 내보내기 자료이며, 이관된 원장을 덮어쓰지 않습니다.
- 기록과 완료 증거를 정확한 플랫폼·세션·입력 receipt·revision·승인된 완료 조건에 연결합니다. Autopilot 작업 완료와 Core 증거를 같은 트랜잭션으로 반영하거나 함께 취소합니다.
- 보호 파일의 수정 시각을 정확한 정수와 불투명 토큰으로 보존해 반올림 때문에 변경으로 오판하는 문제를 막습니다.
- 도구 실행 전에 완료 증거의 출처를 포착하고 현재 작업의 prepare/publish 명령을 제공합니다. 장부 기록만을 위해 업무를 다시 실행하지 않도록 최초 결과와 원래 시각을 재사용합니다.
- 종료 훅의 복구 과정에서도 요청하신 답변을 보존하고, 근거 없는 완료 주장과 과거 실패를 성공으로 바꾸는 처리를 거부합니다.
- 설치 테스트에 두 훅을 모두 포함하고, 파일 보호 회귀 검사가 기존 unittest CI에서 실제로 실행되도록 연결합니다.

## 호환성과 업데이트

Core 0.4.0과 Autopilot 0.4.0을 함께 업데이트하고 다시 설치해 주세요. 새 애드온은 공유 SQLite API를 사용하므로 최소 Core 버전도 0.4.0입니다. 제품 버전 변경으로 내부 스키마 번호를 일괄 변경하지 않습니다.

기존 상태를 이관하기 전에 구형 기록 프로세스를 중지해 주세요. 원본 파일을 보존하고, 사용 중인 SQLite DB는 백업 API 또는 쓰기를 멈춘 일관된 사본으로 백업해 주세요. 초기화된 DB 위에 오래된 JSON을 복원하지 마세요. 과거 릴리스 노트는 그대로 유지합니다.

## 검증과 한계

전달된 구현의 기존 격리 평가에서는 대상·예외 구분, 현재 원본 사용, 실행과 계획 구분, 변경된 입력 처리를 확인했습니다. 게시 대상 실행은 최초 답변 전에 완료 증거를 게시했고 저장만을 위한 재조회는 관찰되지 않았습니다. 선정 사례의 결과이며 일반적인 신뢰성을 보장하지 않습니다. 과거 실패 기록과 평가 한계도 그대로 보존합니다. 종료 훅이 답변을 거부하면 다시 출력될 수 있으며, 이번 변경은 호스트 화면의 중복 표시 자체를 없애지 않습니다.

릴리스 검사는 저장소 CI 워크플로를 사용합니다. 결정적 검사의 통과를 모델 판단 품질이나 검증하지 않은 운영체제 지원의 증거로 취급하지 않습니다. Git 태그와 공개 릴리스 발행은 소스 버전 변경과 별도입니다.

## 라이선스

Apache-2.0 오픈소스 라이선스를 유지합니다.
