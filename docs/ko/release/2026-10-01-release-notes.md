# Ghost-ALICE OS v0.4.1 릴리즈 안내

언어: [English](../../release/2026-10-01-release-notes.md) | 한국어

Core 0.4.1과 Autopilot 0.4.1을 함께 제공하며, 애드온의 기술적 최소 Core 버전은 0.4.0으로 유지됩니다. 내부 스키마와 카탈로그 버전은 그대로 유지되며, 두 저장소 모두 Apache-2.0 라이선스를 유지합니다.

## 변경 내용

- Codex의 조건부 부트스트랩은 완전하게 제공된 프로젝트 계약을 사용하거나 실제 작업 전에 관리되는 전체 대체 계약을 읽습니다.
- Codex 설정에서 전체 프로젝트 지침을 읽을 수 있는 예산을 보존합니다.
- 상세 완료 절차는 필요한 참조에서 읽으며 검증과 감사 요구사항은 유지합니다.
- 상태 질문과 교정 중에도 승인된 작업을 이어가며 명시적인 일시정지, 중단과 범위 교체를 존중합니다.
- 다른 작업 디렉터리와 공백이 포함된 경로에서도 실행 가능한 절대경로 원장 명령을 전달합니다.
- 설치, 진단과 정리 중 사용자 거버넌스 파일과 심볼릭 링크 대상을 보존합니다.
- 완료 보고를 사례별 실제 근거에 연결하며 평가 도구와 런타임 반영을 구분합니다.

## 업데이트

Core와 Autopilot을 함께 업데이트하고 다시 설치해 주세요. 기존 세션 데이터베이스, 사용자 파일과 미결 병합 기록을 보존해 주세요. Codex 부트스트랩과 관리되는 전체 거버넌스 파일은 함께 설치되며 status와 doctor가 의존성을 확인합니다.

## 검증 범위

저장소 CI와 로컬에서 실행 가능한 동일 검사를 사용합니다. 선정한 독립 gpt-6.1-sol Codex 사례에서 유사한 완료 보고 입력, 승인된 작업의 지속과 실제 범위 내 작업 수행을 확인했습니다. Claude 지침 설치를 확인했으며 새로운 Claude 모델 추론은 수행하지 않았습니다. 사례별 근거는 각각의 검증 범위만 뒷받침합니다. 이 결과로 모든 상황의 신뢰성, 인과 효과 크기나 정량적인 토큰 감소를 주장하지 않습니다.
