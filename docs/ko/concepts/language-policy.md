# 언어 정책

[🇺🇸 English](../../concepts/language-policy.md) | [🇰🇷 한국어](./language-policy.md)

Ghost-ALICE OS는 영어를 저장소의 기본 안내 언어로 사용하며, 사용자용 문서는 한국어 대응 문서도 제공합니다.

기여자는 코드, 스키마, 제어 토큰, 이슈 양식, 배포 안내와 기여 절차를 영어 기준으로 관리합니다. 한국어 문서는 한국어 검토자와 기여자가 같은 내용을 이해하도록 돕는 대응 문서입니다.

## 규칙

- 문서 관리자는 저장소의 기본 안내를 영어로 유지합니다.
- 사용자용 저장소 문서에는 `docs/ko/` 아래에 한국어 대응 문서를 유지합니다.
- 문서 관리자는 쌍을 이루는 두 문서를 제목 바로 아래의 언어 전환 줄로 연결하고, 위키 페이지는 이 줄로 시작합니다. 두 판의 줄은 접두어 없는 `[🇺🇸 English](…) | [🇰🇷 한국어](…)` 형식입니다. English 라벨은 영어판을, 한국어 라벨은 한국어판을 가리킵니다. 링크는 저장소에서 현재 파일 기준의 상대 경로를, 위키에서 페이지 이름을 사용합니다. 그래서 독자는 어느 판에서든 두 판 사이를 이동할 수 있습니다.
- 영어 문서의 내부 링크는 기본적으로 영어 문서를 가리킵니다.
- 한국어 문서의 내부 링크는 대응 문서가 있으면 한국어 문서를 가리킵니다.
- 실행 계약과 실행 코드는 주 저장소에서 관리합니다.
- 로컬 체크아웃의 업데이트가 막혀도 조회할 수 있어야 하는 긴 설명 페이지는 영어·한국어 쌍으로 위키에 작성합니다.
- 위키의 영어 페이지는 루트에, 한국어 페이지는 `ko/` 아래에 작성합니다. 폴더마다 자기 언어의 사이드바가 번호를 붙인 문서 순서를 나열합니다. 위키에는 푸터가 없으며, 파일 이름이 곧 페이지 제목입니다.

## 번역하지 않는 토큰

번역자는 다음 토큰의 표기를 바꾸지 않습니다.

- 파일 경로와 디렉터리 이름
- 명령, 옵션과 환경 변수
- JSON, TOML, YAML과 Markdown의 필드 이름
- 열거 값과 스키마 리터럴
- 훅 이름과 스킬 이름
- Codex, Claude Code 같은 플랫폼 이름

토큰 자체는 그대로 두고 주변 설명만 번역합니다.

## 의도적으로 짝이 없는 원본

사용자용 문서, 아키텍처, 위키 설명과 GitHub Pages는 영어·한국어 대응 문서를 유지합니다. 실행 지침 본문(`AGENTS.md`, 플랫폼 부트스트랩, `SKILL.md`), 스키마, 관리자 절차, 커뮤니티 정책, 법적 고지와 출처 기록은 의도적으로 하나의 영어 원본을 기준으로 관리합니다. `CONTRIBUTING.md`, `SUPPORT.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, `LICENSE`, `NOTICE`, `THIRD_PARTY_NOTICES.md`, `.github/` 양식과 `official-docs/`가 여기에 해당합니다. 사용자용 설명은 어느 언어에서든 그 원본을 링크할 수 있으며, 번역된 제어·법적 원본을 따로 작성한다는 뜻은 아닙니다.

## 불일치 관리

문서 관리자는 영어 기준 문서를 먼저 수정하고, 사용자에게 전달되는 의미가 변경되면 같은 변경에서 한국어 대응 문서도 수정합니다. 낡은 부분 페이지는 오해를 일으키는 중복본으로 보존하는 대신 삭제합니다. 한국어 대응 문서를 의도적으로 제공하지 않는 경우에는 가장 가까운 문서 목록에서 그 예외를 설명합니다.
