# Ghost-ALICE OS Planning Policy

언어: [🇺🇸 English](../../plans/README.md) | 🇰🇷 한국어

이 directory는 public planning documents를 위해 예약되어 있습니다. local work queues, private integration notes, customer-specific roadmaps, scratch handoff state에 사용하지 않습니다.

## Public Planning Rules

- contributor-facing work는 GitHub Issues 또는 public roadmap documents에서 추적합니다.
- private deployment plans는 이 repository 밖에 둡니다.
- completed-history notes는 여기에 보존하지 않습니다. Git history, releases, merged pull requests를 사용합니다.
- `.tmp/`와 local notebooks는 scratch로만 취급합니다. public, contributor-relevant decisions만 tracked docs로 승격합니다.

## Current Public Roadmap

이 디렉터리에는 기여자 검토가 가능한 공개 로드맵 항목만 기록합니다.
