# Selecting Skill Evaluations

Use this guide when the author must choose an evaluation method for a demonstrated skill defect.

## Match method to uncertainty

| Skill purpose | Evaluation |
| --- | --- |
| Enforce a rule | Require a concrete action under the relevant pressure. |
| Teach a technique | Apply it to the affected case and a meaningful variation. |
| Recognize a pattern | Include a matching case and a near miss. |
| Provide reference information | Locate and apply the specific information. |
| Route from a description | Use trigger-eval.md to check selection and non-selection. |

An agreement question such as “Do you understand?” tests recitation, not execution.

## Baseline and candidate

Use writing-skills' [Validate and evaluate](../SKILL.md#validate-and-evaluate) procedure for baseline preservation, package validation and affected evaluation. Select time, sunk-cost, authority or simplicity pressures only when they explain the decision being investigated; simulated conditions do not grant production authority.

## Judge the result

Return the observed action, criterion-specific comparison and checked configuration to the author. Partial compliance identifies the unmet requirement. Apply verification-before-completion for what that result supports and whether another observation can change acceptance.
