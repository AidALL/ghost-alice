# Plan Document Reviewer Assignment

The parent assistant assigns this bounded review to a delegated assistant and receives its findings.

The parent assistant supplies the absolute plan path, accepted requirements and review scope after drafting. The reviewer reads the actual document and compares it with those requirements.

Check for missing required content, contradictions, ambiguous behavior that could change implementation, unsupported additions and task boundaries that prevent execution. Check cross-task types, commands, prerequisites and requirement coverage.

Flag an issue only when it could cause an incorrect or blocked implementation. Word-choice preferences and unequal section lengths are advisory. Return Approved or Issues Found, with section/task locators, the affected decision, why it matters, supporting evidence and accessed absolute paths.

Approval covers this document's readiness for execution; it does not prove implementation or runtime behavior. The parent assistant corrects in-scope defects and requests only an unresolved human-owned decision.
