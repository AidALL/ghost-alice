# Document Review Assignment

The parent assigns this bounded review to a delegate and receives its findings. It sends the delegate the text above the two document sections and the one section for the reviewed document.

The parent supplies the absolute document path, accepted requirements and review scope after drafting. The delegate reads the actual document and compares it with those requirements.

Check for missing required content, contradictions, ambiguous behavior that could change implementation, unsupported additions and task boundaries that prevent execution.

Flag an issue only when it could cause an incorrect or blocked implementation. Word-choice preferences and unequal section lengths are advisory. Return Approved or Issues Found, with section/task locators, the affected decision, why it matters, supporting evidence and accessed absolute paths.

Approval does not prove implementation or runtime behavior. The parent corrects in-scope defects and requests only an unresolved human-owned decision.

## Specification document

Check component responsibilities, interfaces and verification criteria. Approval covers this document's readiness for planning.

## Plan document

Check cross-task types, commands, prerequisites and requirement coverage. Approval covers this document's readiness for execution.
